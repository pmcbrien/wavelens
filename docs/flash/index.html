Flash a Wavelens Spotter

Installs the current Spotter firmware (version) onto an ESP32 over USB, from this page. Works in Chrome and Edge on Windows, macOS, Linux and ChromeOS. Phones can't do this (no Web Serial): on Android, update from inside the Wavelens app instead — More → Companion radio → Update firmware, over Bluetooth.

  1. Plug the Spotter (or any ESP32-WROOM-32 dev board) into the computer with a data USB cable.
  2. Click the button, pick the serial port that appears (usually USB Serial / CP210x / CH340), and let it run — about a minute.
  3. When it says done, unplug and plug it back in. The LED blinks twice and it advertises as Wavelens-XXXX; pair it in the app.
This browser can't talk to USB serial. Use Chrome or Edge on a computer. Open this page over HTTPS to flash.

If the port doesn't show up

  • Try another cable; many are charge-only.
  • Windows may need the CP210x or CH340 driver for the board's USB chip (the board's maker links it).
  • Some boards need BOOT held while the connection starts; the Spotter we ship doesn't.

Other ways to update

  • From the phone, no computer: Wavelens app → More → Companion radio → Update firmware. The app carries the firmware inside it; the update goes over Bluetooth in about a minute.
  • From a Scanner Pi: plug the Spotter into the Pi's USB and use the admin page (http://wavelens.local:8080 → Spotter).
  • Command line: pip install esptool, then esptool.py --chip esp32 write_flash 0x0 wavelens-esp32-merged.bin (the image is on the firmware release).

Receive-only firmware; it transmits nothing. Source: companion/esp32. Updates are free for life.
