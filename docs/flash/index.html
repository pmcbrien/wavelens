Flash a Wavelens Spotter

Installs the current Spotter firmware (version) onto an ESP32 over USB, from this page. Works in Chrome and Edge on Windows, macOS, Linux and ChromeOS. Phones can't do this (no Web Serial): on Android, update from inside the Wavelens app instead — More → Companion radio → Update firmware, over Bluetooth.

  1. Plug the Spotter, or any of these dev boards, into the computer with a data USB cable: classic ESP32 (ESP32-WROOM-32 / -32U), ESP32-S3, ESP32-C3, ESP32-C6 or ESP32-C5. The page reads which chip it is and installs the matching firmware. On boards with two USB ports, use the one marked USB (not UART) on a C3, C5 or C6.
  2. Click the button, pick the serial port that appears (usually USB Serial, USB JTAG/serial debug unit, CP210x or CH340), and let it run — about a minute.
  3. When it says done, unplug and plug it back in. The LED blinks twice (white on boards with a colour LED) and it advertises as Wavelens-XXXX; pair it in the app.
This browser can't talk to USB serial. Use Chrome or Edge on a computer. Open this page over HTTPS to flash.

If the port doesn't show up

  • Try another cable; many are charge-only.
  • Windows may need the CP210x or CH340 driver for the board's USB chip (the board's maker links it).
  • Some boards need BOOT held while the connection starts (common on C3 SuperMini and XIAO boards: hold BOOT, tap RESET, let go of BOOT); the Spotter we ship doesn't.

Other ways to update

  • From the phone, no computer: Wavelens app → More → Companion radio → Update firmware. The app carries the firmware inside it; the update goes over Bluetooth in about a minute.
  • From a Scanner Pi: plug the Spotter into the Pi's USB and use the admin page (http://wavelens.local:8080 → Spotter).
  • Command line: pip install esptool, then esptool.py --chip esp32 write_flash 0x0 wavelens-esp32-merged.bin (for another chip swap both names, e.g. --chip esp32c6 and wavelens-esp32c6-merged.bin) (the image is on the firmware release).

Receive-only firmware; it transmits nothing. A C3, C5 or C6 shares one core between Wi-Fi and Bluetooth, so it hears a little less than a classic ESP32; the C5 is the only one that also hears 5 GHz Wi-Fi. Source: companion/esp32. Updates are free for life.
