Set up a Wavelens Scanner

Turns a Raspberry Pi with one or more RTL-SDR dongles into a Wavelens Scanner: one command, about ten minutes, and it starts by itself at every boot. A browser can't write an SD card or reach into a Pi the way it can flash a Spotter, so the Pi runs the installer itself; this page builds the command.

What you need

  • A Raspberry Pi 4 or Pi 5 with its official power supply (the 5 A one on a Pi 5, or its USB ports are held to 600 mA between them).
  • At least one RTL-SDR dongle. More can be added later; the Scanner works out what each one does.
  • A microSD card, and internet on the Pi while the installer runs.

Which Pi, dongle, hub and antenna work: HARDWARE.md.

1. Put Raspberry Pi OS on the card. Use Raspberry Pi Imager and pick Raspberry Pi OS Lite (64-bit). In Imager's settings, set a username and password, your Wi-Fi, and turn on SSH. Put the card in the Pi, plug in the dongles, and power it up.

2. Open a terminal on the Pi. From a computer on the same network: ssh yourname@raspberrypi.local (the username and hostname you set in Imager). A keyboard and screen on the Pi work too.

3. Paste this command and press Enter.

Its admin page will be at http://wavelens.local:8080. Change it if you run more than one.

Only the RTL-SDR Blog V4 needs it, and only on a Raspberry Pi OS whose own driver is older than 2.0. Building it adds about five minutes. Other dongles (RTL-SDR Blog V3, Nooelec NESDR, plain RTL2838) use the driver that comes with the OS.


    

    
4. Pair it. When it says Done, open http://wavelens.local:8080 and set the admin password, then in the Wavelens app: More → Companion radio → Find → Pair.

  


  
What the command does

  
    
    
  • Checks the Pi model, power supply and internet, and tells you what it found.
    • 
    
  • Installs the radio tools (rtl-sdr, rtl_433), Bluetooth and the Scanner's bridge, updater and admin page from the public repository.
    • 
    
  • Stops the kernel's TV driver from taking the dongle, names the Pi, and starts the Scanner as a service.
    • 
    
  • Lists the dongles it can see at the end. It is safe to run again, to repair or after re-imaging the card.
    • 
  

  
Read it before you run it: provision.sh.


  
Digital voice

  
P25, DMR and NXDN voice is a separate, longer build with a patent notice you have to read and accept, so it is not part of the one-line install. After step 3: sudo /opt/wavelens/companion/pi/install-dsd.sh


  
If something is off

  
    
    
  • The page at .local doesn't open: use the Pi's IP address instead (hostname -I on the Pi), port 8080.
    • 
    
  • No dongle listed at the end: try another USB port, then sudo systemctl restart wavelens-bridge. On a Pi 5 with a smaller power supply, more than one dongle needs a powered hub.
    • 
    
  • A V4 hears nothing above VHF or shows PLL not locked: run the command again with the driver option set to Install it now.
    • 
    
  • Anything else: journalctl -u wavelens-bridge -f shows what the Scanner is doing; the admin page has Download log for support.
    • 
  

  
Receive-only; it transmits nothing. Updates are free for life: sudo wavelens-update check, the admin page, or the app's Companion screen. More: UPDATES.md, ADMIN.md.
